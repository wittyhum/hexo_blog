这里这里！！我又报错了，卡了我一天！

就是hexo d的时候报错为：“SSL证书问题:无法获取本地颁发机构证书”，csdn和百度都翻烂了，无论是取消代理设置

git config –global –unset http.proxy
git config –global –unset https.proxy

还是修改端口git config –global http.proxy http://127.0.0.1:7890，都是不行

就在我快要放弃时，突然看到一篇博客，他是直接不验证SSL证书，虽然这会不安全，但对于我个人而言能有什么数据，直接采纳！

首先执行命令

git config --global http.sslVerify false

设置为false，再运行

vim ~/.gitconfig

查看是否成功，要是sslVerify = false 就是设置成功了，这样就能成功推送啦

六、Github Pages

虽然部署成功了，但我还是不能够访问，只能本地访问，所以我使用了Github Pages

首先打开Github，点击创建的仓库->设置->Github Pages

如果你的仓库是私有的，那么你就会像我一样

这时候需要把仓库公开，在这个页面有个搭建和发布，就是source的下拉框，发布方法选择Github Actions，这里是使用jekyll（一款前端框架，可以把一些markdown格式的笔记渲染成前端页面），点击Configure配置就行，继续点击commit changes，这样Actions就创建完毕了，点击上方的Actions按钮，可以看到jekyll正在部署，出现绿色√就是部署完成了，再点击进去就会显示部署成功的地址，打开就可以正常访问这个地址了，这个域名是国内直连的，所以访问速度还是很快的
